# Worksheet Activity

Generator workbook aktivitas anak (rencana halaman + prompt gambar). Web app statis: HTML, CSS, dan JavaScript dalam satu file, tanpa build dan tanpa dependensi.

## Cara pakai
1. Isi Tema, Gaya Visual, Usia Anak, dan Jumlah Halaman.
2. Klik **Buat Rencana Workbook**.
3. Periksa rencana, lalu klik **Setuju & Buat Prompt**.
4. Copy atau download prompt (TXT / MD).

## Deploy ke GitHub Pages
1. Buat repository baru di GitHub, misalnya `worksheet-activity`.
2. Upload `index.html`, `.nojekyll`, dan `README.md` ke branch `main`.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu **Save**.
5. Tunggu 1–2 menit. Situs aktif di `https://USERNAME.github.io/worksheet-activity/`.
